Настройка Google Cloud:
Создайте новый проект в Google Cloud Console (например, под названием «Excel Factory»).
Подключите Google Sheets API в разделе Library.
Создайте сервисный аккаунт (Service Account), назначьте ему роль «Owner» или «Editor» и скачайте ключ доступа в формате JSON.
Интеграция с таблицей:
Создайте новую Google Таблицу и предоставьте доступ к её редактированию вашему сервисному аккаунту (используя email из JSON-ключа).
Разработка:
Создай Python-модуль с CRUD-операциями Google Таблицы через Google API. У меня идет подключение через сервисный аккаунт, JSON-ключ лежит в проекте. После модуля с использованием OOP внизу создай точку входа, в которой пропиши чтение всех ячеек и принт их в консоли для проверки. Модуль должен быть написан так, чтобы его можно было запросто подключить в любое другое приложение и использовать методы этого класса для взаимодействия с таблицей напрямую.Перенесите файл с JSON-ключом в корень проекта.
Создай простенькое приложение с помощью токинтера, которое будет симулировать рандомные отчеты, и от нас будет требоваться только введение парочки полей, например, выбора даты от какого до какого мы хотим получить отчет, каких-то еще парочку полей, и потом это всё будет записываться в гугл-таблицу в виде красивого отчета, в виде документа, как будто это прям вордовский документ, только в экселе с красивым расставлением клеток, автоматическим выносом всех данных и так далее. Для работы с экселем использую @google_sheets.py.
С помощью промпта создайте Python-модуль (например, google_sheets.py) с CRUD-операциями для работы с Google Таблицами через ООП.
Создание симулятора:
Создайте приложение на базе tkinter (файл report_generator.py), которое будет генерировать случайные отчеты и записывать их в вашу таблицу, используя созданный ранее модуль google_sheets.py.
Реализуйте в коде автоматическое форматирование (цвета, шрифты, объединение ячеек) для создаваемого отчёта.
