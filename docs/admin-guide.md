# Руководство администратора

## 1. Назначение

Документ описывает конфигурацию, эксплуатацию и обслуживание Excel Factory.

## 2. Архитектура

```
report_generator.py (tkinter)
        │
        ├── report_data.py      — генерация данных
        ├── ai_client.py        — AITunnel (OpenAI-совместимый API)
        ├── report_builder.py   — модель листа и форматирование
        └── google_sheets.py    — Google Sheets API v4
                    │
                    └── Google Таблица (хранилище отчётов)
```

Приложение настольное, работает от имени пользователя. Собственная база данных
не используется. Каждый отчёт размещается на отдельном листе Google Таблицы.

## 3. Переменные окружения

| Переменная | Обязательна | По умолчанию | Назначение |
|---|---|---|---|
| `GOOGLE_CREDENTIALS_FILE` | Да | `service_account.json` | Путь к JSON-ключу |
| `SPREADSHEET_ID` | Да | — | Идентификатор таблицы |
| `GOOGLE_SCOPES` | Нет | `.../auth/spreadsheets` | Права доступа |
| `AITUNNEL_API_KEY` | Для ИИ | — | Ключ AITunnel |
| `AITUNNEL_BASE_URL` | Нет | `https://api.aitunnel.ru/v1` | Базовый URL API |
| `AITUNNEL_MODEL` | Нет | `deepseek-v4.1-flash-1017` | Модель |
| `AI_TIMEOUT` | Нет | `30` | Таймаут запроса, с |
| `AI_RETRIES` | Нет | `2` | Повторные попытки |
| `LOG_LEVEL` | Нет | `INFO` | Уровень журнала |
| `REPORT_SEED` | Нет | — | Зерно генератора |

После изменения `.env` перезапустите приложение.

## 4. Файлы и каталоги

| Путь | Назначение |
|---|---|
| `.env` | Секреты и настройки (не коммитится) |
| `service_account.json` | Ключ сервисного аккаунта (не коммитится) |
| `logs/app.log` | Журнал, ротация 5 МБ × 3 файла |
| `cache/last_report.json` | Модель последнего отчёта |
| `Техническое_задание.md` | Требования к системе |

## 5. Журналирование

Формат:

```
11.11.2026 19:30:12 | INFO     | excel_factory.gui | Генерация отчёта «Продажи»
11.11.2026 19:30:15 | INFO     | excel_factory.sheets | Создан лист 'Продажи_01.11.2026_30.11.2026'
```

Уровни: `DEBUG`, `INFO`, `WARNING`, `ERROR`. Для подробной диагностики установите
`LOG_LEVEL=DEBUG` и перезапустите приложение. Ключи и приватные данные в журнал
не записываются.

## 6. Обслуживание ключей

### 6.1. Ротация ключа Google

1. Google Cloud Console → **IAM & Admin → Service Accounts**.
2. Выберите аккаунт → **Keys → Add key → JSON**.
3. Замените `service_account.json` новым файлом.
4. Удалите старый ключ из списка ключей.
5. Доступ к таблице сохраняется: email аккаунта не меняется.

### 6.2. Ротация ключа AITunnel

1. Выпустите новый ключ в личном кабинете AITunnel.
2. Замените `AITUNNEL_API_KEY` в `.env`.
3. Отзовите старый ключ.
4. Перезапустите приложение.

### 6.3. Компрометация

При подозрении на утечку немедленно отзовите ключ, выпустите новый,
проверьте `logs/app.log` и историю коммитов (`git log -p`) на наличие секретов.

## 7. Квоты и ограничения

| Ограничение | Значение |
|---|---|
| Запросов на пользователя | 60 в минуту |
| Запросов на проект | 300 в минуту |
| Листов в таблице | до 200 |
| Ячеек в таблице | до 10 000 000 |
| Строк в отчёте | до 1 000 |
| Период отчёта | до 366 дней |

При коде 429 приложение выполняет повторные попытки. При систематическом
превышении уменьшите частоту генерации или используйте отдельный проект Google Cloud.

## 8. Резервное копирование

- **Исходный код:** GitHub-репозиторий.
- **Отчёты:** Google Drive (история версий Google Таблицы).
- **Кэш последнего отчёта:** `cache/last_report.json` — достаточно скопировать файл.
- **Конфигурация:** `.env` и `service_account.json` храните в защищённом месте
  (например, в менеджере секретов). В Git они не попадают.

Восстановление: развернуть проект, вернуть `.env` и ключ, запустить
`python google_sheets.py` для проверки.

## 9. Добавление нового типа отчёта

1. В `report_data.py` добавьте `ReportSchema` в `REPORT_SCHEMAS`.
2. Реализуйте метод генерации данных и зарегистрируйте его в словаре `builders`.
3. Проверьте, что `total_kinds` соответствует столбцам.
4. Запустите тесты:

```powershell
python -m unittest discover -s tests -v
```

Интерфейс подхватит новый тип автоматически: список типов берётся из
`REPORT_TYPES`.

## 10. Диагностика

| Проверка | Команда |
|---|---|
| Версия Python | `python --version` |
| Зависимости | `python -c "import googleapiclient, openai, dotenv; print('OK')"` |
| Доступ к таблице | `python google_sheets.py` |
| Тесты | `python -m unittest discover -s tests -v` |
| Журнал | `Get-Content logs\app.log -Tail 50` |

Перед обращением в поддержку приложите последние 50 строк журнала и текст ошибки
из интерфейса. Не прикладывайте `.env` и JSON-ключ.

## 11. Обновление приложения

```powershell
git pull
python -m pip install -r requirements.txt --upgrade
python -m unittest discover -s tests -v
```

Перед обновлением рекомендуется сохранить копию `.env`.
