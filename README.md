# Excel Factory — Auto-Report-GoogleSheets

Автоматизированная система формирования аналитических отчётов в **Google Таблицах**.
Приложение на Python + tkinter генерирует данные, получает аналитический вывод от
языковой модели и записывает готовый отчёт с полным оформлением на отдельный лист.

## Возможности

- **CRUD для Google Таблиц** через сервисный аккаунт: чтение, запись, добавление,
  очистка, удаление строк и листов.
- **Пять типов отчётов**: продажи, финансы, склад, маркетинг, HR.
- **Автоматическое оформление**: объединение ячеек, фирменные цвета, шрифты,
  границы, ширины столбцов, числовые форматы, чередование строк, закрепление шапки.
- **Диаграмма** по данным отчёта, встроенная прямо в лист.
- **Аналитический вывод ИИ** через OpenAI-совместимый API AITunnel.
- **Резервный сценарий**: если ИИ недоступен, отчёт всё равно создаётся с
  текстом на основе рассчитанных показателей.
- **Уникальные имена листов** и кэш последнего отчёта.
- **Журналирование** в `logs/app.log` с ротацией.

## Требования

- Python **3.10+**
- Windows 10/11 (также работает на macOS/Linux с tkinter)
- Доступ в интернет
- Проект в Google Cloud с включённым **Google Sheets API**
- Сервисный аккаунт с JSON-ключом
- Google Таблица, открытая сервисному аккаунту с ролью **Editor**

## Быстрый старт

### 1. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 2. Настройка Google Cloud

1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/).
2. Включите **Google Sheets API** (`APIs & Services → Library`).
3. Создайте **Service Account** (`IAM & Admin → Service Accounts`).
4. Создайте ключ формата **JSON** и скачайте его.
5. Положите файл в корень проекта под именем `service_account.json`.
6. Создайте Google Таблицу и предоставьте доступ на редактирование
   email сервисного аккаунта (поле `client_email` из JSON).
7. Скопируйте `SPREADSHEET_ID` из URL таблицы.

### 3. Конфигурация

Скопируйте `.env.example` в `.env` и заполните значения:

```env
GOOGLE_CREDENTIALS_FILE=service_account.json
SPREADSHEET_ID=1AbC...ваш_id...XyZ

AITUNNEL_API_KEY=sk-aitunnel-...
AITUNNEL_BASE_URL=https://api.aitunnel.ru/v1
AITUNNEL_MODEL=deepseek-v4.1-flash-1017
```

> `.env` и `service_account.json` исключены из Git через `.gitignore`.
> Никогда не публикуйте эти файлы.

### 4. Проверка подключения

```bash
python google_sheets.py
```

Скрипт подключится к таблице, прочитает все листы и выведет содержимое в консоль.
Для одного листа:

```bash
python google_sheets.py --sheet "Продажи" --max-rows 50
```

### 5. Запуск приложения

```bash
python report_generator.py
```

В окне выберите период, тип отчёта, подразделение и нажмите
**«Сгенерировать отчёт»**. Через несколько секунд появится ссылка на готовый лист.

## Структура листа отчёта

| Блок | Содержимое |
|---|---|
| Заголовок | «Аналитический отчёт „{Тип}“» |
| Подзаголовок | Период отчёта |
| Метаданные | Подразделение, автор, дата формирования |
| Ключевые показатели | 5 KPI со значениями и изменением |
| Детализация | Таблица данных и строка «Итого» |
| Аналитический вывод | Текст ИИ или резервный текст |
| Диаграмма | Столбчатая диаграмма справа от таблицы |

Оформление: палитра `#1F3864` / `#2E75B6` / `#D9E2F3`, шрифт Calibri,
закреплённые первые 5 строк, чередование строк, числовые форматы `₽`, `%`, даты.

## Работа с ИИ

- Провайдер: **AITunnel**, OpenAI-совместимый API.
- Модель задаётся переменной `AITUNNEL_MODEL`.
- Запрос: `temperature=0.3`, `max_tokens=3000`, таймаут 30 секунд.
- При ошибках 429/5xx выполняются до 2 повторов с задержкой 1 и 2 секунды.
- При недоступности провайдера формируется резервный текст, отчёт создаётся полностью.
- Ключ API хранится только в `.env` и не попадает в журналы.

Отключить ИИ можно галочкой **«Аналитический вывод ИИ»** в интерфейсе.

## Диагностика

| Симптом | Решение |
|---|---|
| `Не найден файл ключа сервисного аккаунта` | Положите `service_account.json` в корень проекта или укажите путь в `.env` |
| `Доступ запрещён (403)` | Откройте таблицу сервисному аккаунту (`client_email`) с ролью Editor |
| `Таблица не найдена (404)` | Проверьте `SPREADSHEET_ID` |
| `Превышена квота Google Sheets API` | Подождите минуту и повторите |
| ИИ недоступен | Отчёт создастся с резервным текстом; проверьте ключ и баланс AITunnel |
| Приложение не запускается | Проверьте `pip install -r requirements.txt` и версию Python |

Подробнее — в [docs/installation.md](docs/installation.md) и
[docs/admin-guide.md](docs/admin-guide.md).

## Безопасность

- Используются минимальные права: `https://www.googleapis.com/auth/spreadsheets`.
- Сервисному аккаунту даётся доступ только к конкретной таблице.
- Секреты хранятся в `.env` и `service_account.json`, исключённых из Git.
- В журналы не записываются ключи и приватные данные.
- При компрометации ключа: отозвать ключ в Google Cloud / AITunnel, выпустить новый,
  заменить файл и переменную окружения.
